# React Counter

Um contador simples desenvolvido com **React**.

## Funcionalidades

* ➕ Aumentar o número
* ➖ Diminuir o número
* 🗑️ Zerar o número

## Tecnologias

* React
* JavaScript
* CSS
* Vite

## Como executar

Clone o projeto e instale as dependências:

```bash
npm install
```

Depois, execute:

```bash
npm run dev
```

O projeto será disponibilizado no endereço indicado pelo Vite.

## Objetivo

Projeto desenvolvido para praticar os conceitos básicos de **React**, como componentes, eventos e gerenciamento de estado.
